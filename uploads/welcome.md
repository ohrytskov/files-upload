# Welcome to CloudVault File Repository

CloudVault is a feature-rich, high-performance file management service powered by Node.js and the native `fs` module.

### Features
- 🚀 **Fast Multipart Uploads** with progress bar and drag & drop support.
- 📁 **File Management**: Preview, rename, download, and delete files on the fly.
- 🎨 **Modern Dark UI**: Designed with glassmorphism, responsive grid/list views, and quick search.
- 📊 **Storage Analytics**: Real-time breakdown of storage consumption by category.
